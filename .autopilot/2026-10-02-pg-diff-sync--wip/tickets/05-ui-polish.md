## Что должно заработать

1. **Подписи в ленте «Запуски».** Сейчас задачи показываются сырыми типами `pg_compare` и `pg_diff_load`. Нужны человеческие подписи: «Сравнение баз» и «Загрузка разницы».
   - В `gpcopy_pipeline.js` добавляются две записи в `RUN_LABELS`. Больше в этом файле ничего не меняется.
   - Версия скрипта в шаблоне поднимается.
2. **Опрос сравнения не сбивает выбор.** Пока идёт опрос, открытый select действия не закрывается и не сбрасывается под пользователем.
   - Перерисовываются только изменившиеся строки, либо перерисовка откладывается, пока фокус внутри таблицы.
   - Выбранные пользователем действия и галки сохраняются между опросами.
3. **«Ожидалось» после перезагрузки.** Если открыть страницу заново во время или после загрузки, колонка «ожидалось» снова показывает числа. Они берутся из config задачи `pg_diff_load` (`expected`).
   - Сначала найди существующий маршрут, который отдаёт config задачи, и используй его.
   - Если такого нет, добавь маршрут чтения `GET /api/pg/diff-load/<job_id>` → `{ok, job, expected, tables}`:
     - только для задач `pg_diff_load`;
     - POLICY `sync.view`;
     - проверка доступа к задаче — как у `/api/pg/compare/results`;
     - тест маршрута; тест политики должен остаться зелёным.
