## Что должно заработать

В Postgres Toolkit → «Синхронизация» появляется переключатель «Перенос / Сравнение и разница». По умолчанию выбран «Перенос», он работает как раньше.

Новый режим:

- **Подключения.** Источник и приёмник берутся из существующих селекторов шапки `#gppSrc` / `#gppDst`. Сами селекторы не меняются.
- **Выбор таблиц.** Дерево источника «схема → таблицы» строится по существующему маршруту каталога (найди его в app.py, новый не пиши).
  - Галка на схеме означает «вся схема».
  - Галки на отдельных таблицах можно сочетать с галками на схемах.
  - Есть поиск по имени.
- **Сравнение.**
  - «Сравнить» вызывает `POST /api/pg/compare/start`.
  - Результаты опрашиваются каждые 2–3 с через `/api/pg/compare/results?job_id=`; строки появляются по мере готовности.
  - Видно, какая таблица сравнивается сейчас; сверху — сводка.
  - «Стоп» вызывает существующий `/api/jobs/<id>/stop`.
- **При открытии режима** показывается последнее сравнение этой пары (`/api/pg/compare/latest`) с датой. Если сравнения не было — пустое состояние.
- **Строка результата** показывает статус, ключ и его происхождение, src/dst и сколько строк добавить, изменить и удалить. Действия зависят от статуса:
  - `differs` / `same` — выбор «разница / полная (TRUNCATE + INSERT) / пропустить».
  - `no_dest` — отдельная галка «создать и залить», по умолчанию снята. Над таблицей — «отметить все отсутствующие».
  - `structure_diff` — подсказка про «Проверить DDL» в режиме «Перенос».
  - `no_source` / `error` / `duplicate_keys` — без действий.
- **Галка «Удалять строки, которых нет в источнике»** по умолчанию снята, рядом предупреждение.
- **Загрузка.**
  - «Загрузить» показывает подтверждение с итогами — существующий на странице механизм своих диалогов, не `confirm()`.
  - После подтверждения уходит `POST /api/pg/diff-load/start`.
  - Дальше видны прогресс и итог «ожидалось / сделано» по таблицам.
- **Полная загрузка без сравнения.** Кнопка «Полная загрузка (TRUNCATE + INSERT)» рядом с «Сравнить» грузит выбранные в дереве таблицы, с подтверждением.
- **Лента «Запуски».** `pg_compare` и `pg_diff_load` добавляются в `RUN_TYPES` для pg; версия скрипта поднимается.

Контракты маршрутов — в `interfaces.md`. Таск 02 делается параллельно, поэтому опирайся на контракт, а не на его код. Ошибки API показываются текстом, а не молчанием.

- [ ] Имена:
  - все глобальные функции и id DOM нового режима начинаются с `pgcmp`;

  - опрос результатов;
  - сводка;

- [ ] Подготовка загрузки:
